# 🚂 ISO/IEC 27001:2022 & RGPD Information Security Audit

> **Academic Project** - *Postgraduate Program in Information Security, Cybersecurity and Privacy (SWitCH Cyber)*  
> **Course:** Information Security Audit (ASINF) | **Institution:** ISEP  

This repository contains the complete documentation for the Information Security Audit conducted for **Ferroviária Tech, S.A.**, a simulated critical infrastructure operator in the railway sector.

---

## 📋 Project Overview

The main objective of this project was to perform an internal compliance and security assessment of Ferroviária Tech's Information Security Management System (ISMS) against international standards and European regulations:

- **ISO/IEC 27001:2022** & **ISO/IEC 27002:2022** (ISMS Requirements & Controls)
- **GDPR (Regulation UE 2016/679)** (Data Protection & Privacy)
- **NIS2 Directive (UE 2022/2555)** & **IEC 62443** (OT/SCADA & Critical Infrastructure Security)
- **COBIT 2019** & **ISO 19011:2018** (IT Governance & Auditing Guidelines)

## 🎯 Key Findings & Scope

The audit covered central infrastructure in Lisbon (HQ & Primary DC), operational control centers in Porto (OT/SCADA, Traffic Management System - SGTF), disaster recovery in Aveiro (DR DC), and Microsoft Azure cloud environments.

### Audit Summary:
- **Major Non-Conformities (NCM):** 4 (Risk assessment omitting OT/SCADA assets, unmanaged access privileges, un-tested BCP/DRP for OT, unrecorded security incidents)
- **Minor Non-Conformities (NCm):** 3 (Outdated security policy, unresolved findings from 2025, incomplete security awareness training)
- **Certification Status:** Conditional upon remediation of Major Non-Conformities within 90 days.
